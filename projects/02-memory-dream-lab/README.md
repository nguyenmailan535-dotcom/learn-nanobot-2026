# Project 02 — Memory & Dream Lab

## 实验设计

准备两个 session：A / B。

A 写入：

- 一个稳定身份偏好；
- 一个长期项目事实；
- 一个临时细节。

执行 `/dream` 后，打开 B 验证：

- durable fact 是否恢复；
- 临时细节是否被错误固化；
- `history.jsonl` 与 `USER.md` / `MEMORY.md` 的差别。

## 输出

```text
report.md
├── session evidence
├── files before dream
├── files after dream
├── dream-log
└── one failure / surprise
```
