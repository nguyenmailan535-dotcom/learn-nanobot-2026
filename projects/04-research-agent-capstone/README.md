# Project 04 — ResearchPilot Agent Capstone

## Definition of Done

### Runtime

- [ ] current-source Nanobot runs from editable checkout
- [ ] source trace documented
- [ ] Research capability is a Tool/MCP, not hard-coded prompt text

### RAG

- [ ] >= 5 papers
- [ ] document-aware retrieval
- [ ] grounded answer
- [ ] source-level citation
- [ ] unanswerable behavior

### Eval

- [ ] multi-paper eval set
- [ ] document recall
- [ ] evidence recall
- [ ] answer/citation evaluation
- [ ] bad case taxonomy

### Agent capabilities

- [ ] Skill
- [ ] Agent Plugin or explicit MCP config
- [ ] Dream memory experiment
- [ ] one useful Subagent workflow
- [ ] one useful Automation

### Engineering

- [ ] secrets outside repo
- [ ] workspace restriction reviewed
- [ ] README architecture diagram
- [ ] reproducible setup
- [ ] Docker or system service
- [ ] demo video/GIF

## 最重要的原则

每打一个勾，都要能给出：代码位置、运行命令、输出、一个失败案例。
